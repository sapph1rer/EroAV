# EroAV

แอปเดสก์ท็อปสำหรับดู AV เขียนด้วย Rust + [egui](https://github.com/emilk/egui) ธีมดำ-ชมพู
ดึงรายการวิดีโอจาก MissAV สองเว็บมารวมกันในแอปเดียว และเล่นด้วยตัวเล่นในตัว (rmp / libmpv) ไม่ต้องเปิดเบราว์เซอร์

> ⚠️ เนื้อหาสำหรับผู้มีอายุ 18 ปีขึ้นไปเท่านั้น

## ความสามารถ

- **รวม 2 แหล่งในที่เดียว**: [MissAV (EN)](https://missav.live/dm539/en/new) และ [MissAV123 (CN)](https://missav123.com/dm247/cn/new)
  ทุกหน้ารายการดึงจากทั้งสองเว็บพร้อมกันแล้วสลับกัน เรื่องที่ซ้ำกันจะแสดงครั้งเดียว (ใช้ชื่อภาษาอังกฤษก่อน)
- **Home**: Continue watching (ดูต่อจากที่ค้างไว้) และแถว Hot today / New releases / Popular this week / Top this month
- **New**: วิดีโอใหม่ล่าสุด แบ่งหน้า Prev / Next
- **Discover**: ฟีดเลื่อนดูได้เรื่อย ๆ ถึงล่างสุดแล้วโหลดเพิ่มเอง (วนรายการยอดนิยม ซับจีน uncensored leak ฯลฯ)
- **Search**: ค้นด้วยรหัส ชื่อเรื่อง หรือชื่อนักแสดง พร้อม **Sort** (วันที่ออก ยอดวิววันนี้/สัปดาห์/เดือน/ทั้งหมด ฯลฯ)
  และ **Filter** (Single actress, Japan AV, Asia AV, Uncensored, English subtitle ฯลฯ)
- **หน้าวิดีโอ**: ข้อมูลเรื่อง นักแสดง แนว ซีรีส์ ค่าย กดชื่อเพื่อดูวิดีโอทั้งหมดของชื่อนั้นได้ และมี "More from …" เรื่องที่เกี่ยวข้องด้านล่าง
- **My List**: กดรูปหัวใจบนการ์ดหรือในหน้าวิดีโอเพื่อเก็บเรื่องที่ชอบ
- **History**: ประวัติวิดีโอที่เคยเล่นทั้งหมด (รวมเรื่องที่ดูจบแล้ว)
- **Continue watching**: จำตำแหน่งที่ดูค้างไว้และเล่นต่อจากจุดเดิมอัตโนมัติ
- **Settings**: ขนาด UI, ตั้งค่าการเล่น (engine, hardware decoding, คุณภาพภาพ, smooth motion, deband,
  รวมเสียงเป็นสเตอริโอ, เต็มจอตอนเริ่ม, ระยะการกระโดด) และ **ทดสอบแหล่ง** ทีละขั้น
  (รายการ → หน้าวิดีโอ → ลิงก์สตรีม → ดาวน์โหลดสตรีม)
- ภาพปกและรายการถูกแคชไว้ในเครื่อง เปิดแอปครั้งถัดไปจึงขึ้นทันที แล้วค่อยอัปเดตข้อมูลใหม่เบื้องหลัง
- ใช้ไอคอน (Phosphor) ไม่ใช้อีโมจิ มีแอนิเมชันการ์ด เปลี่ยนหน้า และโหลด

## ความต้องการของระบบ

- Windows 10 / 11 (64-bit)
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (มีมากับ Windows 10/11 อยู่แล้วเกือบทุกเครื่อง)
- `libmpv-2.dll` วางไว้ข้าง `eroav.exe` (ตอน build จะคัดลอกให้อัตโนมัติ) ถ้าไม่มีจะเล่นด้วยเอนจินพื้นฐานของ Windows แทน
- อินเทอร์เน็ตที่เข้าถึง `1.1.1.1` หรือ `8.8.8.8` ได้ (ดูหัวข้อ DNS ด้านล่าง)

## วิธี build และรัน

ต้องมี [Rust](https://rustup.rs/) (edition 2024) และโฟลเดอร์ `rmp` อยู่ข้างโปรเจกต์นี้ (`../rmp`)
เพราะแอปใช้ `rmp-egui` เป็นตัวเล่น และใช้ `../rmp/third_party/libmpv/libmpv-2.dll`

```
Coding/Rust/
├── EroAV/   ← โปรเจกต์นี้
└── rmp/     ← ตัวเล่นวิดีโอ (rmp-egui, libmpv)
```

```bash
cargo run --release
```

ไฟล์ที่ต้องอยู่ด้วยกันใน `target/release/`:

| ไฟล์ | หน้าที่ |
|---|---|
| `eroav.exe` | ตัวแอป |
| `eroav-browser.exe` | ตัวช่วยเปิดเว็บแบบซ่อน (WebView2) สำหรับผ่าน Cloudflare |
| `libmpv-2.dll` | เอนจินเล่นวิดีโอ |

ทดสอบแหล่งจากคอนโซลโดยไม่เปิดหน้าต่าง:

```bash
cargo run -- --probe
```

```bash
cargo run -- --probe "rei kamiki"
```

รันเทสต์:

```bash
cargo test
```

## การใช้งานครั้งแรก

1. เปิดแอป หน้า Home จะโหลดรายการจากทั้งสองเว็บ (ครั้งแรกอาจใช้เวลาไม่กี่วินาที)
2. ถ้ามีหน้าต่าง **"EroAV — verification"** ขึ้นมา ให้ติ๊ก "Verify you are human" ของ Cloudflare หนึ่งครั้ง
   แอปจะจำไว้ ครั้งต่อไปไม่ต้องติ๊กอีก (ปกติจะผ่านเองโดยไม่ต้องติ๊ก)
3. กดการ์ดเพื่อเปิดหน้าวิดีโอ แล้วกด **Play**
4. ในตัวเล่น กด `Esc` หรือปุ่มย้อนกลับเพื่อออก ตำแหน่งที่ดูจะถูกเก็บไว้ใน Continue watching

ถ้าโหลดไม่ขึ้น ไปที่ **Settings › Sources › Test all** จะบอกว่าขั้นไหนพัง

## เบื้องหลังการทำงาน

- **Cloudflare**: ทั้งสองเว็บมี Cloudflare กันบอท โหลดด้วย HTTP ธรรมดาจะได้ 403
  แอปจึงใช้ `eroav-browser.exe` (WebView2 ที่ซ่อนหน้าต่าง) เปิดหน้าเว็บจริง แยกหนึ่งตัวต่อหนึ่งเว็บ และโหลดพร้อมกัน
- **DNS**: DNS ของผู้ให้บริการอินเทอร์เน็ตบางเจ้าไม่ตอบชื่อเว็บพวกนี้ (ค้างจนหมดเวลา)
  แอปจึงมี proxy ภายในเครื่อง (`src/dns.rs`) ที่ค้นชื่อผ่าน DNS-over-HTTPS (1.1.1.1 แล้วค่อย 8.8.8.8)
  ทั้งตัวช่วยเปิดเว็บ ตัวโหลดภาพปก และตัวเล่น mpv วิ่งผ่าน proxy นี้
  **ไม่ต้องเปิดแอป 1.1.1.1 / WARP และไม่แก้การตั้งค่า Windows ใด ๆ** การเชื่อมต่อ HTTPS ยังเข้ารหัสตรงถึงเว็บปลายทาง
- **สตรีม**: ลิงก์ `playlist.m3u8` (surrit.com) ถอดมาจากสคริปต์ที่ถูก pack ไว้ในหน้าวิดีโอ
  ถ้าหาไม่เจอ จะเปิดหน้าเว็บให้เล่นจริงแล้วดักลิงก์ที่ตัวเล่นของเว็บโหลด
- **การอ่านหน้าเว็บ**: ใช้ regex อ่าน HTML (`src/source.rs`) ถ้า MissAV เปลี่ยนหน้าตาเว็บ อาจต้องแก้ตรงนี้

## ข้อมูลที่เก็บในเครื่อง

ทั้งหมดอยู่ที่ `%LOCALAPPDATA%\EroAV\`

| ที่อยู่ | เก็บอะไร |
|---|---|
| `settings.json` | การตั้งค่า, Continue watching, History, My List |
| `lists\` | แคชรายการวิดีโอ (ให้เปิดแอปแล้วขึ้นทันที) |
| `img\` | แคชภาพปก |
| `browser\`, `browser-1\` | โปรไฟล์ WebView2 ของแต่ละเว็บ (คุกกี้ Cloudflare) |

ลบโฟลเดอร์นี้ทิ้งได้ถ้าอยากเริ่มใหม่ทั้งหมด (My List และ History จะหายด้วย)

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `src/main.rs` | จุดเริ่มโปรแกรม, โหมด `--probe`, ไอคอนหน้าต่าง |
| `src/app.rs` | หน้าจอทั้งหมด: แถบซ้าย, Home, New, Discover, Search, My List, History, Settings, หน้าวิดีโอ, ตัวเล่น |
| `src/source.rs` | แหล่ง MissAV: URL, อ่านรายการ/หน้าวิดีโอ, ถอดลิงก์สตรีม, รวมสองเว็บ, แคช, ทดสอบแหล่ง |
| `src/browser.rs` | คุยกับ `eroav-browser.exe` (JSON ทีละบรรทัดผ่าน stdin/stdout) |
| `src/bin/eroav-browser.rs` | ตัวช่วย WebView2 ที่ซ่อนหน้าต่าง: โหลดหน้าเว็บ ผ่าน Cloudflare ดักลิงก์วิดีโอ |
| `src/dns.rs` | proxy ภายในเครื่องที่ค้นชื่อผ่าน DNS-over-HTTPS |
| `src/images.rs` | โหลดและแคชภาพปก |
| `src/settings.rs` | การตั้งค่า, Continue watching, History, My List และค่าที่ส่งให้ตัวเล่น rmp |
| `src/theme.rs` | สี ฟอนต์ (รองรับไทย/จีน/ญี่ปุ่น) และสไตล์ egui |
| `build.rs` | คัดลอก `libmpv-2.dll` ไปไว้ข้าง exe ตอน build |

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| หน้าค้างที่ "Refreshing" นาน / ขึ้น "can't reach the site" | ตรวจอินเทอร์เน็ต แล้วลอง Settings › Sources › Test all ถ้าเครือข่ายบล็อกทั้ง 1.1.1.1 และ 8.8.8.8 ให้ใช้ VPN หรือ WARP |
| ขึ้น "Cloudflare check not done" | ติ๊กช่องในหน้าต่าง "EroAV — verification" แล้วกด Try again |
| เปิดสองหน้าต่างพร้อมกันแล้วโหลดไม่ขึ้น | เปิดแอปทีละหน้าต่างเท่านั้น (สองตัวจะแย่งโปรไฟล์ WebView2 กัน) |
| กด Play แล้วเล่นไม่ได้ | ดูว่ามี `libmpv-2.dll` ข้าง `eroav.exe` (Settings › Playback จะบอก) และลอง Test ของแหล่งนั้น |
| รายการว่าง "Nothing found" ทั้งที่เว็บยังมี | เว็บอาจเปลี่ยนหน้าตา ต้องแก้ตัวอ่าน HTML ใน `src/source.rs` |
